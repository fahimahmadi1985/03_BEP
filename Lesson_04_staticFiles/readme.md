## Serving static files with Express

- So far, we have been working with APIs that return JSON data
- But what if we want to serve a website?
- A website is a collection of files: HTML, CSS, JavaScript, images, etc.
- Some of these files are static: they don't change
- Some of these files are dynamic: they sometimes change

- Express can serve static and dynamic files
- Let's build a backend with Express and serve a website
