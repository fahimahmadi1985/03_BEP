# Task 1

This exercise is about practicing problem solving, focusing on how to build a dynamic page using EJS templates in Express.

You will be building a page that displays a product datasheet for a fictional product of a fictional company. This very realistic exercise is based on multiple real world projects.

First, examine the existing code. Then add your own to complete the exercise.

When the existing `/datasheet-pdf/:productCode` endpoint is called, it calls the `/datasheet/:productCode` template and converts the returned page into a datasheet PDF. Your datasheet page and the resulting PDF must match the example [reference.pdf](./reference.pdf) as close as possible.
